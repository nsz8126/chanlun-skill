# 缠论分析技能

## 概述

本技能基于chanlun库（Rust实现的缠论分析引擎）和eltdx库（通达信7709协议），提供A股市场的缠论分析功能。

**核心架构**：Python识别买卖点 → AI验证分析 → 生成报告

## 核心思维框架

### 三大核心理念

1. **不测而测** - 不预测市场未来，只分析当下正在发生什么
2. **完全分类** - 事先列出所有可能情况，为每种情况准备应对策略
3. **级别思维** - 任何分析都必须明确级别，不同级别有不同的操作策略

### 操作原则

- **生存第一**：永远不要让一次失败毁掉所有
- **机械操作**：严格按照系统操作，不加入个人情绪
- **节奏把握**：识别底、顶以及中间过程，在不同阶段采用不同策略

## 分析思维流程

当需要分析交易机会时，按以下顺序思考：

### 1. 明确级别
- 这是什么级别的机会？（周线？日线？30分钟？5分钟？）
- 我的操作级别是什么？
- 级别是否匹配？

### 2. 识别结构
- 当前处于什么结构？（上涨？下跌？盘整？）
- 在结构的什么位置？（起点？中间？末端？）
- 中枢在哪里？

### 3. 判断买卖点
- 是第几类买卖点？（一买、二买、三买？）
- 确认条件是否满足？
- 有无背驰？

### 4. 评估风险收益
- 止损位在哪？
- 目标位在哪？
- 风险收益比如何？

### 5. 制定策略
- 买入/卖出的具体位置？
- 仓位多少？
- 后续如何应对各种情况？（完全分类）

## 混合架构

### 架构设计

```
第一层：Python快速识别（确定性逻辑）
├── 获取笔、中枢数据
├── 应用缠论规则
├── 输出候选买卖点
↓
第二层：AI分析验证（智能分析）
├── 验证信号合理性
├── 结合多周期分析
├── 评估风险收益
├── 生成详细报告
```

### 分工

| 层级 | 职责 | 输出 |
|------|------|------|
| Python | 规则匹配 | 候选信号列表 |
| AI | 智能分析 | 最终结论+理由 |

## 标准买卖点识别

### 一买（趋势背驰买点）

**条件：**
1. 下跌趋势确认（至少2个向下笔）
2. MACD背驰（价格新低，MACD未新低）
3. 终点在中枢下方

**AI验证要点：**
- 趋势是否足够强
- 背驰是否明显
- 是否有止跌信号

### 一卖（趋势背驰卖点）

**条件：**
1. 上涨趋势确认（至少2个向上笔）
2. MACD背驰（价格新高，MACD未新高）
3. 终点在中枢上方

**AI验证要点：**
- 趋势是否足够强
- 背驰是否明显
- 是否有滞涨信号

### 二买（回调不破位买点）

**条件：**
1. 一买后出现回调
2. 回调低点高于一买低点
3. 出现止跌信号

**AI验证要点：**
- 回调幅度是否合理
- 是否有支撑确认
- 成交量是否配合

### 二卖（反弹不破位卖点）

**条件：**
1. 一卖后出现反弹
2. 反弹高点低于一卖高点
3. 出现滞涨信号

**AI验证要点：**
- 反弹幅度是否合理
- 是否有压力确认
- 成交量是否配合

### 三买（中枢突破买点）

**条件：**
1. 价格突破中枢上沿
2. 回踩不破中枢上沿
3. 出现确认信号

**AI验证要点：**
- 突破是否有效
- 回踩是否确认
- 是否有量能配合

### 三卖（中枢跌破卖点）

**条件：**
1. 价格跌破中枢下沿
2. 反弹不破中枢下沿
3. 出现确认信号

**AI验证要点：**
- 跌破是否有效
- 反弹是否确认
- 是否有量能配合

## 多周期分析

### 级别体系

| 周期 | 级别 | 用途 |
|------|------|------|
| 月线 | 长线 | 定大方向 |
| 周线 | 中线 | 找大区间 |
| 日线 | 短线 | 找机会 |
| 30分钟 | 日内 | 找区间 |
| 5分钟 | 日内T | 精确定位 |
| 1分钟 | 日内T | 入场点 |

### 共振分析

- **跨周期共振**：不同周期同时出现买卖点
- **同级别共振**：同一周期内不同级别的信号叠加
- **共振强度**：三重共振 > 双重共振 > 单一信号

## 数据与表达纪律

1. **先确认数据**：明确标的、数据时间范围、周期、复权方式和数据来源。缺少关键数据时，先说明限制并请求数据，不要编造价格、信号或当前行情。
2. **区分事实与判断**：先列出可观察的K线结构、分型、笔、线段、中枢和指标，再给出缠论解释；标注不确定性和不同划分可能造成的差异。
3. **避免确定性荐股**：输出教育性分析和条件化预案，不承诺收益，不把技术信号表述为必然上涨或下跌，也不替用户决定具体投资金额。
4. **风险优先**：任何策略都要包含失效条件、止损或退出条件、仓位约束和未触发时的等待方案。
5. **当前行情要验证**：如果用户询问实时或近期行情，只有在获得并核验可靠数据后才分析；否则明确说明无法确认最新状态。

## 关键提醒

在所有分析中都要强调：

1. **永远强调级别** - 任何分析都要先明确级别
2. **不做预测** - 只分析当下，不预测未来
3. **完全分类** - 列出所有可能情况和应对
4. **纪律为王** - 强调严格执行系统信号
5. **风险第一** - 生存比盈利更重要
6. **避免情绪化** - 客观分析，机械操作
7. **反复强调** - 你不是多头也不是空头，你只是等待市场自己的选择

### Python 脚本工具

本技能提供了两个实用的 Python 脚本，帮助你快速上手使用 chanlun 库进行缠论分析：

1. **chan_analyzer.py** - 缠论综合分析工具（结构分析 + 买卖点信号 + 背驰判断 + 技术指标 + 线段级分析）
2. **example_workflow.py** - 自动化执行完整分析流程的示例脚本

脚本只用于复现结构计算和整理输入数据，不能替代对级别、数据质量和交易风险的判断。优先使用本地 CSV 进行可复现分析；使用 `eltdx` 在线数据源前先确认依赖、网络和数据源可用（该源官方仅授权个人学习与非商业研究使用）。

> 运行环境：Python >= 3.11。需安装 chanlun 和 eltdx 库：`pip install chanlun eltdx`

**快速开始：**

```bash
# 基础分析（本地 CSV，离线可复现，推荐）
python scripts/chan_analyzer.py \
    --source csv \
    --input scripts/test_data.csv \
    --symbol 000001 \
    --freq 日线

# 在线获取（eltdx）
python scripts/chan_analyzer.py \
    --source eltdx \
    --code sh600519 \
    --start_date 20240101 \
    --end_date 20240614 \
    --freq 日线

# 启用技术指标
python scripts/chan_analyzer.py \
    --source csv --input scripts/test_data.csv --symbol 000001 \
    --cal_macd --cal_rsi --cal_kdj

# 启用线段级分析
python scripts/chan_analyzer.py \
    --source csv --input scripts/test_data.csv --symbol 000001 \
    --analyze_seg_level

# 或者使用示例工作流脚本一次性完成（默认走脚本目录下的本地样例数据）
python scripts/example_workflow.py

# 示例工作流切到在线数据源
python scripts/example_workflow.py --source eltdx --code sh600519 --days 180
```
