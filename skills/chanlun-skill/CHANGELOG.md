# Changelog

## 4.1.0 - 2026-10-09

### Added

- 发布标准信号 `signal-1.0` JSON Schema，并加入 Draft 2020-12 校验测试。
- 新增 Windows 离线 CI、Rust observer 适配冒烟测试和真实周期粒度的多周期回归。

### Changed

- 各周期改为直接构造独立 Rust `观察者` 分析，不再依赖 `立体分析器` 私有 observer 容器或自动周期合成。
- 按职责拆分 CLI、数据源、报告、结构事实、背驰证据、信号分类和分析输出模块。
- 测试脚本及 fixtures 统一迁移至 `tests/`，移除 `scripts/` 中的旧测试副本。
- 修复非相邻重复时间统计，并明确无时区 CSV 日期按 UTC 解释。

## 4.0.0 - 2026-09-21

### Breaking Changes

- 标准信号移除 Rust 买卖意义、指标匹配、买卖点 factory 止损和 `可执行` 字段。
- 标准信号改用 `结构有效性`、`结构有效性依据`、`结构失效边界` 与 `结构失效条件`。
- 运行时脚本与测试资产分离：fixtures 位于 `tests/fixtures/`，回归脚本位于 `tests/unit/` 和 `tests/integration/`。

### Changed

- 一、二、三类买卖点的确认和失效仅依据缠论结构。
- 一类在出现反向笔后，以背驰或反向笔重新进入前中枢的小转大确认；小转大适用于趋势和盘整。
- AI 仅在用户明确请求时基于结构结果生成条件化策略与仓位管理建议。
