# 使用场景示例

## 场景1：股票买卖点分析

### 用户问题
"请分析 sz000001（平安银行）的日线级别买卖点"

### 分析思路

1. **明确级别**：日线级别
2. **获取数据**：获取足够的日线K线数据
3. **分析结构**：识别当前趋势和中枢
4. **判断买卖点**：检查是否有买卖点信号
5. **评估风险**：给出止损位和目标位

### 示例输出

```
## sz000001 日线级别分析

### 当前结构
- 当前处于下跌趋势
- 最近一个中枢区间：[12.50, 13.20]
- 当前价格：11.80

### 买卖点信号
- ✅ 出现一买信号
- 信号时间：2024-06-14
- 信号价格：11.80

### 背驰确认
- MACD背驰：是
- 价格创新低：11.80 < 前低12.00
- MACD柱面积：当前0.8 < 前段1.2

### 操作建议
- 买入区间：11.80 - 12.00
- 止损位：11.50（跌破前低）
- 目标位：13.20（中枢上沿）
- 风险收益比：1:4

### 完全分类
1. **情况A**：反弹进入中枢
   - 应对：持有，目标13.20
2. **情况B**：反弹不进入中枢
   - 应对：减仓，等待三卖
3. **情况C**：继续下跌
   - 应对：止损11.50
```

## 场景2：多周期联立分析

### 用户问题
"请分析 sh600519（贵州茅台）的5分钟、30分钟、日线级别"

### 分析思路

1. **级别联立**：日线定方向，30分钟找买卖点，5分钟找精确入场
2. **多周期共振**：检查各周期信号是否一致
3. **综合判断**：给出多周期综合建议

### 示例输出

```
## sh600519 多周期分析

### 日线级别
- 趋势：上涨趋势
- 当前位置：中枢上方
- 信号：无明显买卖点

### 30分钟级别
- 趋势：上涨趋势
- 当前位置：回调中
- 信号：接近二买位置

### 5分钟级别
- 趋势：下跌趋势
- 当前位置：接近前低
- 信号：等待一买确认

### 综合判断
- 日线方向向上，支持做多
- 30分钟回调接近买点
- 5分钟等待企稳信号

### 操作建议
- 等待5分钟级别出现一买
- 确认后小仓位介入
- 止损设在5分钟前低
- 目标看30分钟前高
```

## 场景3：大盘行情分析

### 用户问题
"请分析当前大盘行情"

### 分析思路

1. **纠正预测思维**：不预测涨跌，分析当下结构
2. **多级别共振**：周线、日线、分时综合分析
3. **完全分类**：列出所有可能情况和应对策略

### 示例输出

```
## 大盘行情分析

### 当前数据
- 标的：上证指数（sh000001）
- 周期：日线
- 时间范围：2024年1月-6月

### 结构分析
- 周线级别：盘整趋势
- 日线级别：下跌趋势
- 30分钟级别：下跌趋势

### 关键位置
- 周线中枢：[3000, 3200]
- 日线中枢：[3050, 3150]
- 当前点位：3080

### 多空力量
- 空方力量：较强
- 多方力量：较弱
- 关键支撑：3050

### 完全分类
1. **情况A**：反弹突破3150
   - 应对：转为看多，目标3200
2. **情况B**：在3050-3150震荡
   - 应对：观望，等待方向选择
3. **情况C**：跌破3050
   - 应对：看空，目标3000

### 操作建议
- 当前不适合大仓位操作
- 等待方向明确后再操作
- 关键位置突破可小仓位跟进
```

## 场景4：交易策略制定

### 用户问题
"请帮我制定 sz000001 的交易策略"

### 分析思路

1. **了解用户**：级别、风险承受能力
2. **基于结构**：给出具体点位
3. **设定止损**：明确止损位
4. **完全分类**：说明各种情况的应对

### 示例输出

```
## sz000001 交易策略

### 用户信息
- 操作级别：30分钟
- 风险承受能力：中等
- 资金规模：10万元

### 当前结构
- 30分钟级别：下跌趋势接近尾声
- 最近中枢：[12.50, 13.20]
- 当前价格：11.80

### 具体点位
- 买入区间：11.80 - 12.00
- 止损位：11.50（跌破前低）
- 目标位1：12.50（中枢下沿）
- 目标位2：13.20（中枢上沿）

### 仓位管理
- 首次买入：30%仓位（3万元）
- 加仓条件：突破12.50后回调不破
- 加仓比例：30%仓位（3万元）

### 完全分类
1. **情况A**：反弹进入中枢
   - 应对：持有，目标13.20
   - 盈利预期：10%-12%

2. **情况B**：反弹不进入中枢
   - 应对：减仓50%，等待三卖
   - 风险控制：止损11.50

3. **情况C**：继续下跌
   - 应对：全部止损
   - 最大亏损：2.5%

### 风险提示
- 止损必须严格执行
- 不要追涨杀跌
- 保持耐心等待信号
```

## 场景5：背驰检测

### 用户问题
"请检测 sh600000（浦发银行）的背驰情况"

### 分析思路

1. **获取数据**：足够的K线数据
2. **计算指标**：MACD等技术指标
3. **识别背驰**：检查是否有背驰信号
4. **确认信号**：多指标确认

### 示例输出

```
## sh600000 背驰检测

### 检测参数
- 周期：日线
- 时间范围：2024年1月-6月
- 指标：MACD（12,26,9）

### 背驰信号
- ✅ MACD背驰：是
- ✅ 斜率背驰：是
- ⚠️ 测度背驰：待确认

### 详细分析
1. **MACD背驰**
   - 价格创新低：7.80 < 前低8.00
   - MACD柱面积：当前0.6 < 前段1.0
   - 背驰确认：是

2. **斜率背驰**
   - 前段下跌斜率：-0.05
   - 当前下跌斜率：-0.03
   - 斜率减小：是

3. **测度背驰**
   - 前段跌幅：8.00-7.50 = 0.50
   - 当前跌幅：8.20-7.80 = 0.40
   - 幅度减小：是

### 操作建议
- 背驰信号较强
- 可关注一买机会
- 等待企稳确认
- 止损设在前低下方
```

## 注意事项

1. **数据质量**：确保数据完整、准确
2. **级别明确**：任何分析都要先明确级别
3. **风险控制**：任何策略都要包含止损
4. **完全分类**：列出所有可能情况
5. **纪律执行**：严格按照系统操作
6. **避免情绪化**：客观分析，机械操作
