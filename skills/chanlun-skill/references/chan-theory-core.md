# 缠论核心理论

## 概述

缠论（缠中说禅理论）是由缠中说禅（李彪）在2006-2008年间提出的完整投资理论体系。本理论基于《教你炒股票》系列108课，提供了一套科学、系统的市场分析方法。

## 核心概念

### 1. 分型

分型是缠论中最基础的概念，由三根K线组成：

- **顶分型**：中间K线的高点是三根K线中最高的
- **底分型**：中间K线的低点是三根K线中最低的

分型是判断趋势转折的关键信号。

### 2. 笔

笔是连接相邻顶分型和底分型的线段：

- **向上笔**：从底分型到顶分型
- **向下笔**：从顶分型到底分型

笔的构成条件：
1. 顶分型和底分型之间至少有一根独立K线
2. 顶分型和底分型之间不能共用K线

### 3. 线段

线段是至少由三笔组成的结构：

- **向上线段**：由奇数笔组成，终点高于起点
- **向下线段**：由奇数笔组成，终点低于起点

线段的结束需要满足特征序列的分型条件。

### 4. 中枢

中枢是至少三段连续次级别走势类型的重叠区间：

- **中枢区间**：[max(所有段的低点), min(所有段的高点)]
- **中枢级别**：构成中枢的段的级别

中枢是多空双方争夺的关键区域。

### 5. 走势类型

走势类型分为两种：

- **趋势**：至少包含两个同向中枢
- **盘整**：只包含一个中枢

## 买卖点理论

### 一买/一卖

**一买**：下跌趋势中，最后一个中枢之后出现背驰
**一卖**：上涨趋势中，最后一个中枢之后出现背驰

特点：
- 通常出现在趋势末端
- 风险收益比高
- 需要背驰确认

### 二买/二卖

**二买**：一买之后回调不破一买低点
**二卖**：一卖之后反弹不破一卖高点

特点：
- 风险相对较低
- 确认性更强
- 适合稳健操作

### 三买/三卖

**三买**：回调不进入中枢的买点
**三卖**：反弹不进入中枢的卖点

特点：
- 通常出现在趋势中继
- 确认中枢突破
- 趋势延续信号

## 背驰理论

### 趋势背驰

在趋势中，最后一段与前一段相比：
- 价格创新高/低
- 但MACD柱面积减小
- 或MACD指标未创新高/低

### 盘整背驰

在盘整中，离开中枢的一段与进入中枢的一段相比：
- 价格幅度减小
- 或MACD指标减弱

## 级别理论

### 级别划分

- **1分钟级别**：1分钟K线构成的走势
- **5分钟级别**：5分钟K线构成的走势
- **30分钟级别**：30分钟K线构成的走势
- **日线级别**：日线K线构成的走势
- **周线级别**：周线K线构成的走势

### 级别联立

- **本级别**：当前分析的级别
- **次级别**：比本级别小的级别
- **高级别**：比本级别大的级别

操作原则：
- 本级别定方向
- 次级别找买卖点
- 高级别定仓位

## 操作哲学

### 不测而测

不预测市场未来，只分析当下正在发生什么。根据当前结构，完全分类所有可能情况，为每种情况准备应对策略。

### 完全分类

事先列出所有可能情况，为每种情况准备应对策略。不预测哪一种情况会发生，只在情况发生时执行对应策略。

### 纪律执行

严格按照系统操作，不加入个人情绪。生存第一，永远不要让一次失败毁掉所有。
